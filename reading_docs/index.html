遇到和记忆冲突时，以这里为准

⚠️ 其中一条会改变推理结果

Gemma 2 的 attn_logit_softcapping 在默认后端下被静默丢弃。 它只在 eager / flash_attention_2 / flex_attention 下真正执行； 而 HF 的默认后端是 sdpa，sdpa_attention_forward 的签名只有 **kwargs， soft-cap 被吞掉——不报错、不警告。

也就是说，直接加载一个 Gemma 2 推理，拿到的是没有 soft-cap 的模型，数值上与官方实现不一致。 要复现官方行为需显式指定 attn_implementation="eager"（或 flash）。 （final_logit_softcapping 不受影响，它作用在 lm_head 输出上。）

已经不存在了 删除与改名 8 条

流传的说法实测真相出处
_attn_implementation_autoset 会按硬件自动挑后端已从库中移除。只剩「默认 sdpa，不可用则静默降级 eager」2A1
cache_position / cache_kwargs已删除。源码原话："This arg has been removed from the Transformers library"2A3、1A5
LogitsWarper 基类不存在。warper 直接继承 LogitsProcessor1A5

tokenizer 有 PreTrainedTokenizer / PreTrainedTokenizerFast 两个类都降级成别名。真实类是三个 backend；AutoTokenizer(use_fast=) 被静默吞掉1A4
config.rope_scaling已改名 rope_parameters，rope_scaling 只剩 property 别名1A2、2A4
rope_config_validation 负责 RoPE 校验已废弃，全库零调用者。校验搬到了 RotaryEmbeddingConfigMixin.validate_rope2A4

语义反了 方向或含义搞错 7 条

流传的说法实测真相出处
T5 是 Post-Norm实测是 Pre-Norm——norm 藏在各子层内部，T5Block.forward 里一个 norm 都没有，所以「看起来像 post-norm」2M4
T5 对 input embedding 做了缩放没有。model_dim**-0.5 只用在 decoder 输出侧2M4
fusion_mapping.py 把 fused 层拆开方向相反：它把运行时模型改成 fused，再注册映射让原始 checkpoint 仍能加载2A6
专家并行用 all-to-all 通信all_to_all 全库零命中。是 all-reduce 合成输出2A6
ModernBERT 的滑动窗口与 Mistral 同向它是双向 band（abs(q_idx - kv_idx) <= w）；Mistral 是因果的（只看左边）。encoder 里「不能看未来」不成立1M5
_LazyAutoMapping 靠 __getattr__ 做惰性导入它没有 __getattr__。惰性来自 _load_attr_from_module 里的 importlib.import_module1A1
特化了 attention 的模型不能用 sdpa / FA看后端有没有对应的表达方式，不是看模型有没有特化。Gemma 2 特化了 soft-cap，但 FA 签名里恰好有 softcap → 可用；真正不能用的是 attention sink 那类（5 个模型），sdpa 没有「多加一列」的接口，作者才写 _supports_sdpa = False2A7

静默行为 不报错，但结果不同 6 条

流传的说法实测真相出处
Gemma 2 的 soft-cap 总生效默认 sdpa 后端静默丢弃（grep -c softcap integrations/sdpa_attention.py → 0）2M1
三家 MoE 都有负载均衡辅助损失DeepSeek V2/V3 没有，靠 e_score_correction_bias 做无辅助损失均衡2M3
BERT 的 MLM loss 只对被 mask 的位置算模型算全序列 cross-entropy；位置筛选在数据侧（collator 把其余位置填 -100）1M5
映射表用 None 表示「不支持该任务头」模型映射表里 None 出现 0 次。None 只在 tokenizer / processor 映射里表示「可选依赖没装」1A1
LLaVA-NeXT 屏蔽 image token 的 loss模型内没有这个屏蔽，图像位置默认要算 loss2M6
不指定 attn_implementation 的模型都用 sdpa_supports_sdpa 默认是 False（要显式 opt-in）。没声明的 141 个文件里有 13 个走了 functional 接口 → 什么都不传时抛错被吞、静默降级 eager，except 里无任何日志2A7
